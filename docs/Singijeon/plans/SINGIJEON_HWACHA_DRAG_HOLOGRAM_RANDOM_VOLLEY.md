# 목적

화차를 잡은 채 플레이어가 이동하면 화차가 따라오게 하고, 화차 형상 홀로그램 위치에 근접 배치하면 성공 처리하며, 전탄을 10초 동안 무작위 순서로 한 발씩 발사한다.

**상태: 완료 (2026-08-21)**

# 현재 상태

- 운반 컴포넌트는 단일 손 이동을 지원하지만 `BP_SingijeonHwacha`에 실제 Grab Component가 없다.
- 목표 표시는 원판 Cylinder라서 화차 배치 방향과 크기를 전달하지 못한다.
- 자동 장전은 재진입·성공 보고의 명시적 1회 보장이 부족하다.
- 발사는 고정 인덱스 순서와 0.08초 간격을 사용한다.

# 구현 범위

- 좌우 손잡이 Grab Component와 Core의 범용 Actor Grab 알림 연결
- 손/플레이어 월드 이동량 기반 화차 추종
- 화차 메시 기반 반투명 홀로그램과 근접 배치·스냅 성공
- 자동 장전 및 `Hwacha_Load` 보고 1회 보장
- 10초 전탄 랜덤 순차 발사

# 변경 예정 파일

- Core `VRPlayerPawn.h/.cpp` 및 `docs/Core/`
- 신기전 화차·운반 C++와 테스트
- `BP_SingijeonHwacha`, `LV_Singijeon`, 홀로그램 Material
- 신기전 구성·검증 스크립트와 문서

# 구현 단계

1. 실제 Blueprint Grab 연결 진단 및 좌우 손잡이 추가
2. Actor Grab/Release 알림으로 운반 시작·종료
3. 화차 홀로그램 목표와 배치 판정
4. 중복 장전 차단과 랜덤 발사 큐
5. 빌드·자동화·에셋 검증

# 다른 Feature에 미치는 영향

Core 변경은 Feature Actor가 선택적으로 받는 범용 Grab 알림뿐이다. 화차 로직과 에셋은 `GF_Singijeon` 내부에 한정한다. `ARCHITECTURE.md`는 수정하지 않는다.

# 검증 방법

좌·우 단독 Grab 추종, Grab Component 존재, 1발 장전 후 총 90발, 중복 호출 시 90발 유지, 홀로그램 도착 성공, 10초 랜덤 전탄 소진을 자동 검사한다.
