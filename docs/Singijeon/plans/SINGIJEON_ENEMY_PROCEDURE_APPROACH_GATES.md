# 목적

적군의 최종 도착 경로는 유지하되 플레이어의 신기전 발사 절차보다 먼저 화차에 도달하지 못하게 단계별 접근 거리를 제한한다.

**상태: 완료 (2026-08-21)**

# 현재 상태

- 적군 Wave는 첫 화살 장전 시 시작한다.
- 시작 후 `ChargeSpeed`로 계속 이동해 화차 배치·횃불·도화선 절차 중에도 목표에 도달할 수 있다.
- 화차는 장전, 배치 완료, 점화, 발사 상태를 이미 소유한다.

# 구현 범위

- 장전, 화차 배치, 도화선 점화, 발사 단계별 Route 접근 비율
- 단계 게이트 도착 시 Tick 정지 및 다음 절차에서 재개
- 전탄 발사 후 생존자만 최종 도착점까지 이동 허용
- 단계별 비율의 Blueprint 조정 지원

# 구현 단계

1. 화차 배치 완료 이벤트를 제공한다.
2. Enemy Wave가 화차 절차 이벤트를 구독한다.
3. Route 이동량을 현재 단계 상한으로 제한한다.
4. 발사 종료 후 생존자 처리와 자동화를 검증한다.

# 다른 Feature에 미치는 영향

`GF_Singijeon` 내부 변경으로 한정하며 Core, Shared, 다른 Game Feature는 수정하지 않는다. `ARCHITECTURE.md`는 수정하지 않는다.

# 검증 방법

- 각 단계 상한값과 순차 증가 확인
- 상한 도달 후 추가 Tick에도 전진하지 않는지 확인
- 다음 절차에서 이동이 재개되는지 확인
- 전탄 발사 후 생존자가 최종 목적지에 도달 가능한지 확인
